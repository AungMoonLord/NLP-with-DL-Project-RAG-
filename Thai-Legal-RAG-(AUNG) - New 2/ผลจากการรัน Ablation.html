อ่านตารางอย่างไร

Recall@k
เอกสารที่ถูกต้องอยู่ใน k อันดับแรกที่ดึงมาหรือไม่ (1.0 = ทุกคำถามเจอ) — Recall@1 คือเจอเป็นอันดับแรกเลย
MRR
ค่าเฉลี่ยของ 1/อันดับที่เจอเอกสารถูก ยิ่งเข้าใกล้ 1.0 ยิ่งถูกอยู่อันดับต้น ๆ
Latency
เวลาเฉลี่ยต่อคำถามของขั้น retrieval (มิลลิวินาที)

สรุปผล

ทุกโหมดหาเอกสารเจอภายใน 5 อันดับแรกครบ (Recall@5 = 1.0) ความต่างอยู่ที่ ความแม่นของอันดับแรก: Dense 0.90 → BM25 และ Hybrid 0.95 → Hybrid + Rerank 1.00 และ MRR เพิ่มจาก 0.9500 เป็น 1.0000

Hybrid ได้ Recall@3 = 1.0 โดยช้าลงเพียง ~1.7 เท่าของ Dense ส่วนการ Rerank ได้อันดับสมบูรณ์แต่ latency สูงมาก

ข้อควรระวัง

  • Latency ของ Hybrid + Rerank ≈ 24.9 วินาทีต่อคำถาม (~287× ของ Dense) สูงผิดปกติสำหรับ Cross-Encoder ที่ให้คะแนน 30 คู่ อาจมาจากการรันบน CPU หรือรวมเวลาโหลดโมเดลเข้าไปด้วย ควรตรวจวิธีวัดก่อนนำไปรายงาน (เช่น warm-up ก่อนจับเวลา)
  • ตัวอย่างน้อย — ถ้าชุดทดสอบมี 20 ข้อ Recall@1 ที่ต่างกัน 0.90 / 0.95 / 1.00 คือต่างกันข้อละ 1 ข้อ จึงยังสรุปว่าดีกว่าจริงไม่ได้ ควรดู Bootstrap CI และ p-value ที่ run_ablation.py คำนวณไว้ประกอบ
  • ตารางนี้ไม่มี Hit และ nDCG ซึ่ง Mind Map ระบุว่าวัดไว้
